# Realm Striders

A cooperative monster-hunting game: prepare at the base, enter a pocket
dimension, capture monsters with equipment, and bring their cages back to sell.

Open the project in **Unity 6000.3.13f1** (Unity 6.3). The project uses URP,
Netcode for GameObjects and Facepunch Steam transport.
